\section{Results}

We compare several fine-tuned LLMs with traditional machine learning (ML) classifiers on the same dataset of 393 patient assessments and examine how performance varies with the number of training shots and serialization format. Unless otherwise noted, all results are reported on the held-out test set defined in Chapter 3.

\end{itemize}

The following sections describe these results in detail.

\subsection{Performance of Traditional Machine Learning Baselines}
Logistic regression, random forest, and XGBoost were trained using the structured feature vectors described in Chapter 3. Their test-set AUC values appear in the bottom rows of Table 2.

Overall, the ML baselines achieve reasonable discrimination between severe and non-severe cases. Among them, XGBoost attains the highest AUC, followed by random forest and logistic regression. However, even the best baseline remains below the strongest LLM configurations. These baselines therefore provide a realistic but clearly improvable reference point for evaluating the benefit of generative LLMs.

\subsection{LLM Performance Across Shot Settings}
We evaluate several pretrained LLMs under different shot settings: 0, 2, 4, 8, 16, and 32 training examples. The models include LLaMA2-7B and multiple Flan-T5 variants, each fine-tuned with LoRA on serialized patient assessments.

The results in Table 2 show three consistent patterns:
\begin{itemize}
    \item \textbf{Zero-shot performance is already meaningful.} In the 0-shot column, some models achieve non-trivial AUC values even without task-specific fine-tuning, indicating that pretrained LLMs contain useful prior knowledge about general health and symptom concepts.
    \item \textbf{Few-shot fine-tuning substantially improves performance.} Moving from 0 to 2 shots leads to a noticeable AUC increase for most models. Additional shots (4-32) usually yield further, but smaller, gains. This confirms that a small number of labeled examples is sufficient to adapt the models to the COVID-19 severity prediction task.
    \item \textbf{Different LLMs respond differently to additional shots.} For some models, performance saturates quickly after a few shots; for others, AUC continues to improve up to 16 or 32 shots. This suggests that model architecture and pretraining details influence how efficiently each LLM uses limited labeled data.
\end{itemize}
Taken together, Table 2 demonstrates that fine-tuned LLMs can match or exceed the performance of strong ML baselines using only a modest number of training examples.

\subsection{Effect of Serialization Format}
As described in Chapter 3, we consider two serialization formats for converting structured features into text inputs: list templates (-L) and text templates (-T). The suffixes ``-L'' and ``-T'' in Table 2 denote these two formats.

The results show that serialization format has a clear impact on performance:
\begin{itemize}
    \item For some models, especially at lower shot counts, list serialization yields higher AUC than text serialization.
    \item For others, especially at higher shot counts, text serialization overtakes the list format.
    \item The relative advantage can also depend on the model: a configuration that benefits from list prompts in early shots may benefit more from text prompts when the training set grows.
\end{itemize}
These trends highlight that the way structured patient data is verbalized into natural language is not just a cosmetic choice; it directly affects how effectively the LLM can use the information. Selecting an appropriate serialization scheme is therefore an important design decision in LLM-based clinical prediction pipelines.

\subsection{Zero-Shot Versus Few-Shot Behavior}
The zero-shot column in Table 2 provides a baseline for what is achievable without any task-specific fine-tuning. In this regime, some models perform comparably to weaker ML baselines, while others lag behind. This variability reflects differences in how well each pretrained model's prior knowledge aligns with the COVID-19 severity task.

In contrast, the 2-shot and 4-shot results show that even a very small labeled set dramatically stabilizes LLM performance. Several models quickly surpass all ML baselines once they see just a handful of serialized examples. Beyond 8--16 shots, improvements continue but with diminishing returns, suggesting that the few-shot regime is the most efficient operating point for this dataset size.

From a practical perspective, these results support the intended use case of the app: a small curated dataset of previous assessments is sufficient to adapt the LLM to provide reliable risk scores, without requiring the large training sets typically needed by traditional ML approaches.

The results suggest that:
\begin{itemize}

These metrics support the conclusion that the proposed LLM-based approach is practically viable for real-time risk assessment, especially in scenarios where missing a truly severe case is costly.

\subsection{Explainability and Attention-Based Feature Importance}
The attention-based explanation mechanism described in Chapter 3 was applied to fine-tuned models to visualize which serialized features contributed most to the predicted risk. The resulting heatmaps, illustrated in Figure 4, provide several insights:
\begin{itemize}
    \item High-risk predictions are usually associated with increased attention to features such as age group, presence of chronic conditions, and key symptoms (e.g., fever, shortness of breath).
    \item For lower-risk predictions, attention tends to shift toward benign or absent risk factors.
    \item Across different models and prompts, qualitatively similar patterns emerge, suggesting that the LLMs are leveraging clinically meaningful features rather than arbitrary tokens.
\end{itemize}
These explanations are not a formal causal attribution, but they align with common clinical reasoning and can help both patients and clinicians understand why a particular risk score was produced. In the context of the mobile app, this interpretability layer complements the numerical prediction and enhances user trust.

\subsection{Summary of Findings}
In summary, the results in this chapter show that fine-tuned generative LLMs achieve performance that is competitive with or superior to strong ML baselines on COVID-19 severity risk prediction using a relatively small structured dataset. Even in the zero-shot setting, some pretrained LLMs provide meaningful risk estimates, but fine-tuning with a small number of examples yields substantial gains. Additionally, the serialization format significantly influences LLM behavior, and careful design of list or text templates can improve performance. Overall, LLMs offer favorable precision-recall trade-offs compared with traditional models and additionally provide natural-language explanations and attention-based visualizations.

These findings support the central claim of this thesis: generative LLMs, when equipped with appropriate serialization, fine-tuning, and explanation strategies, are a promising foundation for conversational, real-time health risk assessment applications.
